# WATT 관리 화면 동작 명세

## 공통

- 검색: 입력 즉시 또는 Enter/검색 버튼으로 현재 행을 대소문자 무시 필터링한다.
- 정렬: 정렬 가능한 헤더 클릭 시 오름차순/내림차순을 전환한다.
- 행 클릭: 편집 모달을 연다. 추가 버튼은 빈 편집 모달을 연다.
- 엑셀/프린트: 데모에서는 동일한 버튼 피드백을 제공하고 프린트는 브라우저 인쇄를 연다.
- 페이지 버튼은 현재 페이지를 강조한다.
- hover: 액션 버튼 `#2062bf` → `#2b76df`, 행 배경 → `rgba(26,35,126,.4)`.

## 화면별

- 위젯 설정: 체크박스로 표시 여부, 숫자 입력으로 순서를 변경하고 열 수를 3/4/5로 선택한다.
  저장 시 현재 상태를 유지하며 완료 메시지를 표시한다. 미리보기 아이콘은 hover 카드가 나타난다.
- 알람 설정: 시작/종료 시간, 전압·전류·전력 임계값, 알람 여부를 행 단위로 편집하고 저장한다.
- 복합제어기: 모드전환으로 표시 모드를 자동/수동 사이에서 바꾼다.
- 시퀀스: 모드전환, 전체 OFF, 전체 ON이 표 상태에 반영된다.
- 실시간 데이터: Gate 필터와 업데이트 멈춤 토글이 있으며 실행 중에는 값이 주기적으로 변한다.
- 통신상태 불량: 계측설비/제어설비 분류를 선택해 조회한다.

## 반응형

- 1440px: 셸 좌측 200px, 일반 관리 패널 2rem 패딩.
- 768px: 내비게이션 숨김, 본문 전체 폭, 일반 표는 가로 스크롤.
- 390px: 상단에는 업체 선택·프로필·햄버거만 남고 패널은 1rem 패딩.
- 위젯 설정은 1024px 이하에서 2열을 1열로 전환한다.
- 관리 표는 화면별 핵심 4열만 노출하고 나머지는 숨긴다. 원본의 모바일 복합제어기 화면은
  `GATE/이름/모드/순위`, 통신상태 화면은 `DEVICE/업체/타입/이름/갱신일`을 표시한다.

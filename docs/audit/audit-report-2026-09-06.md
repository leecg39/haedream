## 개인정보

**P01 · High · 실제 업체 덤프의 공개 전달.** Git에 추적되는 업체 JSON과 이를 포함한 공개 JavaScript 청크에 연락처·주소·고객번호가 존재합니다. 청크는 쿠키 없이 200으로 내려옵니다. 인증 없는 업체 API도 해당 필드를 전체 목록으로 반환합니다. 공통 원인의 API 인증 문제는 S01에 기록했으며 여기서는 정적 번들과 데이터 배포를 별도로 평가했습니다. [번들 일치값 집계](2026-09-06/evidence/client-data-scan.json), [공개 청크 확인](2026-09-06/evidence/functional-probes.json)

우선 실제 데이터를 서버 전용 저장소로 이동하고 공유 상수를 분리해 클라이언트 번들 유입을 차단해야 합니다. 공개 fixture에는 합성 데이터를 사용해야 합니다. 이미 공유·배포했다면 그 범위에 따라 빌드 산출물과 과거 데이터 배포 이력도 확인해야 합니다. 외부 공개 또는 유출이 이미 일어났다고 단정하지 않습니다.

**P02 · Medium · 데이터 수명주기와 자격증명 보관 정책의 증거 부족.** 연락처·주소·한전 원문 데이터의 보유 기간, 삭제·익명화, 접근 이력 정책을 확인하지 못했습니다. 한전 자격증명은 `.gitignore` 대상 로컬 JSON으로 분리되어 있고 서버 파일에서 읽습니다. 애플리케이션 차원의 해당 파일 암호화는 없으며 OS 디스크 암호화·파일 권한·키 관리 운영은 이번 평가에서 확인하지 않았습니다. 사용 목적과 대상에 맞는 보유·삭제·접근 정책과 운영 자격증명 저장 방식을 정해야 합니다.

## 라이선스

**L01 · Medium · 복제한 원본 자산의 이용 근거 미확인.** 원본 사이트의 HTML·JS·폰트·이미지와 화면 디자인을 복제한 자료가 포함되어 있습니다. 소유권이나 허락이 없다는 뜻은 아니지만, 저장소 안에서 외부 배포 범위를 설명하는 권리 확인 자료를 찾지 못했습니다. 공개·상업 배포 범위에 맞게 원본 자산의 출처와 허용 조건을 문서화해야 합니다.

**L02 · Medium · 허용 조건이 다른 의존성의 배포 검토 필요.** `agentation`의 라이선스 메타데이터는 PolyForm Shield-1.0.0입니다. 로컬 LICENSE에는 경쟁 제품 관련 제한과 고지 유지·라이선스 동봉 조건이 있습니다. 현재 React 레이아웃은 개발 환경에서만 렌더링하지만 패키지는 production dependencies에 있고 정적 번들 생성 경로도 있습니다. 내부 개발용 사용과 판매 제품에 포함한 배포를 구분해 검토해야 합니다. 실제 충돌을 확인한 결과는 아닙니다. [프로젝트 LICENSE](https://github.com/benjitaylor/agentation/blob/main/LICENSE), [공식 라이선스 안내](https://www.agentation.com/)

`package-lock.json`의 패키지 항목 509개에서 라이선스 메타데이터를 수집했습니다. 운영체제별 선택 패키지도 포함한 수치입니다. MIT 397, Apache-2.0 38, ISC 18, MPL-2.0 25, LGPL 단독 10과 Apache/MIT 결합 항목 4개 등이 있습니다. LGPL/MPL이라는 이유만으로 이 프로젝트와 충돌한다고 판단하지 않았습니다. 원본 미러·vendor 자산은 이 집계 밖에 있습니다. [전체 집계](2026-09-06/evidence/licenses.json)
